📧 Email Preprocessing
  1. Lowercase all text
  2. HTML tag removal (BeautifulSoup)
  3. URL → URLTOKEN, Phone → PHONETOKEN
  4. Strip non-alphabetic characters
  5. NLTK English stop-word removal
  6. Porter stemming (NLTK)
🔗 URL Preprocessing
  1. Strip scheme prefix (http/https/ftp://)
  2. Remove leading www. subdomain
  3. Tokenise on delimiters (/ . - _ ? = & @ %)
  4. Char-level TF-IDF (char_wb, 3–5 grams)
  5. Extract 15 structural hand-crafted features
  6. MinMaxScaler + scipy.sparse.hstack

🎯 3-Tier Model Selection Strategy — Security-Domain Aware · Applied after GridSearchCV
TIER 1
Macro F1-Score
Highest 5-fold CV macro F1. Weights both classes equally — critical for imbalanced datasets like SMS Spam (87/13 split).
TIER 2
Malicious Recall
Highest recall on spam/phishing class within 0.5% tolerance. False negatives (missed threats) are more costly than false positives in security.
TIER 3
Inference Speed
Fastest inference latency within 0.5% tolerance. Ensures real-time detection (<5ms). Disqualifies Random Forest (203ms) despite highest URL F1.
DQ
Disqualification
Any model with hold-out test F1 < 0.90 is eliminated before tier evaluation. All 5 models passed this gate on both tasks.
